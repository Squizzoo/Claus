With several screens the pet can move to the screen of the window you are working in, keeping its place (bottom right stays bottom right). It waits a few seconds first, so it does not chase every click.

Click-through

While no chat needs you, clicks go straight through the pet to the window below. Hold Ctrl and hover over it to grab it. A finished chat that is muted does not count as needing you.

Claude Code hooks

Claus hears about finished chats, questions and approvals through a few hooks in Claude Code's settings file. They only talk to this computer. Installing or removing them asks first and keeps a backup.

Start with Windows

Claude Desktop

Hide the pet while Claude Desktop is not running and bring it back when you open Claude. Only the Desktop app counts, not Claude Code in a terminal.

Chat tab

The Chat tab of Claude Desktop has no hooks, so Claus watches its Stop button instead and chimes when a reply is finished. This only works while the Claude window is on screen and not covered by other windows (on a second monitor, or side by side): Windows stops a covered window from updating, so a reply that finishes behind other windows is not noticed. It also only sees the conversation that is showing: once you open another tab in Claude (Code, Cowork), a reply still streaming can no longer be followed. No message text is read. This keeps Claude Desktop's accessibility support switched on while it runs.
